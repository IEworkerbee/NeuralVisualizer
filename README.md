# NeuralVisualizer

A quick python script that generates mp4's that showcase the evolution of a neural net's weights over the training process.

## Running the project

1. Start the virtual environment
   **Windows**
   `.venv\Scripts\activate`
   `python main.py`

   **Mac and Linux**
   `source .venv/bin/activate`

2. Run main.py
   `python main.py`
